蓝河应用开发

蓝河应用采用类 Web 开发范式，通过 UI 组件搭建页面布局、样式描述界面效果、JavaScript 处理业务逻辑，
支持 MVVM 架构，数据变化时自动驱动视图更新。

三种应用形态

应用
完整功能，支持多页面、复杂 UI 交互与应用间跳转，可在后台运行。
表盘
支持普通与 AOD 模式、动态交互与 20 多种数据展示，可 AI 生成或代码实现。
快捷卡片
表盘界面左滑即可查看信息与控制操作，无需进入应用。

两套 API

JavaScript API
提供完整开放能力，覆盖生命周期、系统弹窗、多设备互联，开发效率高。
Native API
面向高性能场景，支持 Posix API 及连接、存储、通信等能力，便于复用原有代码。

开发环境：BlueOS Studio

一站式集成开发环境，支持编码、实时预览、调试与打包，提供 Element、Network、Storage 调试面板与 UI 自动化测试，可完成从开发到发布的全流程。

项目文件结构

├── scripts                 工具脚本
├── src
│   ├── assets              公用资源
│   │   ├── images          图片资源
│   │   └── styles          应用样式
│   ├── pages               页面目录
│   │   ├── Demo            应用首页
│   │   └── DemoDetail      详情页
│   ├── app.ux              全局逻辑与应用生命周期
│   └── manifest.json       应用配置、接口声明、页面路由
├── jsconfig.json           语法校验
└── package.json            模块与配置信息

manifest.json 配置

包含应用描述、接口声明（features）与页面路由（router）。使用接口前须先在 features 中声明。

{
  "package": "com.example.demo",
  "name": "发票小助手",
  "icon": "/assets/images/logo.png",
  "versionName": "1.0",
  "versionCode": 1,
  "appCategory": ["utilities"],
  "features": [
    { "name": "blueos.communication.network.fetch" }
  ],
  "config": { "designWidth": 466 },
  "router": {
    "entry": "Demo",
    "pages": {
      "Demo": { "component": "index" },
      "DemoDetail": { "component": "index" }
    }
  }
}

页面示例 index.ux

<template>
  <div class="page">
    <text class="title">{{ title }}</text>
    <input placeholder="请输入内容" onchange="onInput" />
  </div>
</template>

<style>
  .page { flex-direction: column; align-items: center; padding: 20px; }
  .title { font-size: 20px; color: #34d399; }
</style>

<script>
  export default {
    data() {
      return { title: '你好，蓝河' }
    },
    onInput(e) {
      this.title = e.value
    }
  }
</script>

通用开发流程

  1. 准备环境：安装 BlueOS Studio，新建项目获得初始配置与示例页面。
  2. 开发 UI：使用 UI 组件与样式在 .ux 文件中搭建界面，支持弹性与自适应布局。
  3. 开发业务：按需选择 JS API 或 Native API，并在 manifest 中声明所用接口。
  4. 调试：实时预览，配合 Element / Network / Storage 面板定位问题并查阅日志。
  5. 打包发布：用打包功能生成 rpk 包，前往发布平台上架。
蓝河系统兼容快应用标准，可使用 BlueOS Studio 直接开发快应用，存量快应用可便捷迁移至蓝河生态。
