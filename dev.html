云服务 API

GET/api/v1/user/{uid}
获取用户信息（昵称、等级、余额、连续签到天数）
POST/api/v1/signin
每日签到，返回连续天数与奖励积分
POST/api/v1/ticket
提交工单，参数 title / description
GET/api/v1/activities
获取活动列表（含报名链接）
// 示例：签到
fetch('https://api.zhanxu.cloud/v1/signin', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer <token>' },
  body: JSON.stringify({ device: 'watch' })
}).then(r => r.json())

表盘 SDK

基于 AOSP WatchFace 引擎，支持 466×466 圆形/方形表盘，提供 AOD 低功耗模式、心率/步数/天气数据接入。 

// 表盘示例
WatchFace.create({
  size: 466,
  aod: true,
  layers: [
    { type: 'background', color: '#080b12' },
    { type: 'time', font: '72px bold', color: '#73b8ff' },
    { type: 'heart_rate', pos: [233, 380] }
  ]
})
